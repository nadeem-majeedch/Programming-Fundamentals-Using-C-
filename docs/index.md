# Programming Fundamentals Using C++

> Welcome! This is the online home of a complete, free, self-study course.
> Repository: [nadeem-majeedch/Programming-Fundamentals-Using-C-](https://github.com/nadeem-majeedch/Programming-Fundamentals-Using-C-)

## 🚀 Start here — 30 minutes to your first program

1. **[Getting Started](getting-started/index.md)** — install a C++ compiler
   ([Windows](getting-started/compiler-setup/windows.md) ·
   [Linux](getting-started/compiler-setup/linux.md) ·
   [macOS](getting-started/compiler-setup/macos.md) · or use an
   [online compiler](getting-started/compiler-setup/online-compilers.md)),
   then compile the course's
   [sanity-check program](toolchain/sanity-check.cpp).
2. **[How to Study](how-to-study.md)** — the read → run → modify → solve →
   debug → revise method. Two minutes to read; the whole course works better
   with it.
3. **[Lesson 1](cpp-foundations/lesson-1-structure.md)** — what a program
   looks like, and your first C++ program.

That's it — you're a programmer in training.

---

## What this course is

A **beginner-to-advanced journey through programming fundamentals**, taught
entirely in C++, designed so you can study it **without an instructor**:

- **16 units · 32 sessions** — one unit per week at 5–7 hours/week, or your
  own pace.
- **Every concept** has examples you run, modify, and break.
- **Every unit** has exercises, a lab with starter + solution, a quiz with a
  full answer key, debug activities, challenges, and a revision sheet.
- **Three projects** (Weeks 5, 10, 16) consolidate your skills, ending with a
  capstone: a Contact Management System.

The full plan: **[Syllabus](syllabus.md)**.
