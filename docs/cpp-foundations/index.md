# C++ Foundations

> The language toolkit module · ~6–8 h of study + practice · [← Course home](../index.md)

## What this module is

The Problem-Solving module taught you to **think**; this one teaches the
**words**. Every concept a beginner needs before control flow:

- **Structure** — program shape, `main()`, statements, comments
- **Data** — variables, identifiers, naming, integer/floating/character/
  boolean/string types, constants, literals, declaration/initialization/
  assignment
- **Operations** — arithmetic, relational, logical, increment/decrement,
  compound assignment, operator precedence
- **Conversion** — implicit conversion, explicit casting, and the common
  data-type mistakes that cause real bugs

Every concept follows the same four beats: **plain-language explanation →
syntax → worked example → explanation of the example → practice pointer**.

## Try-first protocol (same as always)

The practice sets below include **full answers** — attempt, write, compile
*before* opening them. The rule and why:
[Try It Yourself](../problem-solving/index.md#try-it-yourself-before-looking-at-the-solution).

## Prerequisites and what's next

You need: a working toolchain ([Getting Started](../getting-started/index.md))
and the problem-solving habits ([IPO, trace tables](../problem-solving/index.md)).
This module condenses and extends what the syllabus spreads across
[Unit 01](../units/unit-01-introduction-to-programming-and-cpp/index.md) and
[Unit 02](../syllabus.md#stage-a--foundations) — study it **alongside** those
units, not instead of their labs and quizzes. After this module,
[Unit 04](../syllabus.md#stage-b--control-flow) (decisions) and
[Unit 05](../syllabus.md#stage-b--control-flow) (loops) build directly on
the operators and types you now own.
