## How each session page is organized

Every session below follows the same eleven-part contract:

**title · prerequisites · learning objectives · concepts · recommended
reading · examples to study · exercises · lab/practice · challenge ·
estimated self-study time · completion checklist** — all with working links.

## The session protocol (same every time)

1. **Before the session (10 min):** read the objectives; skim the lesson's
   headings so you know where you're going.
2. **The 2 hours:** read the lesson actively — *type every example into your
   editor, compile, run, then modify one thing and re-run.* That modify-
   and-rerun loop is the course's core learning engine.
3. **Same day (30–60 min self-study):** the session's exercises.
4. **Before the week ends:** the lab, then the challenge, then the weekly
   quiz ([W-keys](../self-assessment/index.md)) — quiz ≥ 90% closes the week.
5. **Stuck?** 20-minute rule: try, trace, then read one hint — never the
   solution first. [When something breaks](../how-to-study.md#what-to-do-when-something-breaks).

**Total journey:** 32 sessions × 2 h + ~60 h self-study ≈ **125–130 hours**
over 16 weeks — a genuine beginner-to-intermediate C++ foundation.
